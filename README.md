# Kurt John Rom — CS Portfolio

A redesigned, responsive personal portfolio for Kurt John Rom, built from the content of the original GitHub Pages portfolio.

## Run locally

Open `index.html` directly in a browser, or use any static server. For example with Python:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages

1. Upload the contents of this folder to your GitHub repository.
2. Keep `index.html` at the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select the branch containing the portfolio and the `/ (root)` folder.
5. Save and wait for GitHub Pages to publish.
